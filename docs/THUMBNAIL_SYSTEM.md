# Thumbnail System — Does It Automate?

Status: DRAFT v0.1

## Objective

Win the click while preserving the promise of the video.

The thumbnail must communicate the experiment, outcome, conflict, or measurable stake in under one second.

## Brand recognition

Use a repeatable visual grammar, not the exact same template.

Core ingredients:
- dark or neutral high-contrast base,
- real product UI / workflow / result when possible,
- one dominant outcome or conflict,
- large readable number/phrase,
- directional annotation only when useful,
- brand accent used selectively,
- minimal decorative AI imagery.

## Text rule

Aim for **0–4 words** on the thumbnail.

Good:
- FAILED 37%
- $17 / MONTH
- 24 HOURS
- 7 AGENTS
- NOT READY
- IT WORKED
- 3 TOOLS → 1

Bad:
- full video title repeated on thumbnail,
- paragraphs,
- tiny labels,
- generic “AI IS CRAZY” copy.

## Proof-first visuals

Prefer:
1. real software interface,
2. real experiment output,
3. actual graph / number / failure state,
4. before-vs-after workflow,
5. recognizable product icon only when it materially helps.

Avoid:
- random robots,
- glowing brains,
- stock cyberpunk faces,
- fake dashboards,
- generic generated backgrounds that do not support the story.

## Packaging process

For every long-form video:

1. Generate 10 title hypotheses.
2. Select 3 strong title directions.
3. Generate 3 thumbnail concepts for the strongest title directions.
4. Score each on:
   - curiosity,
   - clarity,
   - credibility,
   - emotional/stakes signal,
   - mobile readability.
5. Publish the best combination.
6. Use YouTube title/thumbnail testing when available.
7. Log CTR and watch-time results back into NINFA analytics.

## Relationship between title and thumbnail

They should complement each other, not duplicate.

Example:

Title:
**I Gave an AI Agent 100 Real Tasks — Here's Where It Failed**

Thumbnail:
**FAILED 37%**

## Face policy

A human face is optional, not mandatory.

Use the creator's face only when:
- reaction is part of the story,
- presence materially increases trust,
- the experiment benefits from a human protagonist.

The brand must remain recognizable without a face.
