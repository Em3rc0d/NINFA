## Purpose

- compare the real Pictory workflow with the NINFA local stack,
- separate convenience from control,
- test the doctrine that recurring tools must **earn their seat**.

## Comparison result

Observed in this project:

- Pictory was faster to a usable first draft.
- Pictory required less setup.
- NINFA gave materially more scene/evidence control.
- NINFA aligned better with real UI/log/result-driven technical content.
- The local experiment required $0 in new paid video-editor / video-generation API spend.

This does not imply zero total cost; hardware, electricity, internet and engineering time remain real costs.
