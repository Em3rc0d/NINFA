# Does It Automate — Voice Reference Checklist

Use a reference only when the selected segment has:

- one speaker,
- natural speaking voice,
- roughly 10–30 seconds of clean speech,
- no background music if possible,
- no intro sting or sound effects,
- low room echo,
- no clipping,
- no aggressive denoising artifacts,
- normal pace and tone.

## Cross-language production pattern

The validated NINFA test used:

- Spanish reference clip,
- English narration text,
- narration text language set to English,
- CFG weight 0.0,
- exaggeration around 0.5,
- temperature around 0.8.

The language selector describes the narration text language, not the reference language.

Do not commit personal reference voice files to GitHub.
