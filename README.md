# Project NINFA

**Autonomous AI Media Engine**

NINFA is an English-first AI media project focused on building, testing, and explaining practical AI systems, software, agents, and automations that create measurable real-world outcomes.

## Current phase

**MK0.1 — Channel thesis, identity, first content batch, and production prototype**

## North star

Build an autonomous, profitable English-language technology media business where YouTube is the primary distribution channel and the content engine is the compounding asset.

## Canonical persistence

- **GitHub:** technical source of truth — research, decisions, architecture, code, analytics schemas, experiments.
- **Google Drive:** operational/media archive — videos, thumbnails, scripts for review, branding, exports, datasets.
- **ChatGPT context:** continuity layer — project objective, current phase, frozen decisions, and pointers to durable artifacts.

## Channel thesis

We build, test, and explain AI systems that actually do useful work.

Primary content themes:
- Build & Automate
- Experiments & Stress Tests
- Replace / Compare / Decide
- Business & Economics

Target long-form duration: **8–16 minutes**, normally **10–14 minutes when the topic supports it**.

Target automation: **90–95% of production operations**, with human editorial approval and real research/experiments.

See [docs/CHANNEL_THESIS.md](docs/CHANNEL_THESIS.md).
