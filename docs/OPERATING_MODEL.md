# Operating Model

## Persistence

- **GitHub** — technical source of truth: thesis, MKs, architecture, decisions, research summaries, code, prompts/config, analytics schemas, experiment definitions and cost models.
- **Google Drive** — operational/media archive: renders, Shorts, thumbnails, footage, audio, scripts for review, branding, research exports, datasets and publication packages.
- **ChatGPT context** — continuity layer: project identity, current phase, frozen decisions and pointers to durable artifacts. It is not the canonical store for detailed state.

## Production loop

Market signals → topic scoring → research → experiment/build → outline → script → fact-check → scene/demo plan → media capture/generation → narration → render → packaging → QA → human approval → upload/schedule → analytics/revenue/cost → learning loop.

## Engineering principle

Reuse audited open-source commodity plumbing where it saves time. Build NINFA's differentiated market intelligence, research quality, experiment design, opportunity scoring, editorial logic, learning loop and revenue tracking ourselves.

## Capital principle

Available budget is not a spending target. Spend where it measurably improves quality, learning velocity, distribution performance or unit economics.
